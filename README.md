# QSim Studio Web

Monaco Editor 기반 웹 양자 컴퓨팅 IDE.

## Features
- Monaco Editor with OpenQASM/Qiskit support
- Real-time circuit visualization
- Drag & drop gate insertion
- qsim-cluster API integration
- 12 quantum algorithm templates
- Virtual filesystem with auto-save

## Getting Started
```bash
npm install
npm run dev
```

## Tech Stack
Next.js 15, TypeScript, Tailwind CSS, Monaco Editor, Recharts, Zustand

## API Configuration
Settings (⚙️) → Connection → Enter qsim-cluster API URL and token
